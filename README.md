# GNPS2 corpus pipeline — status page

`index.html` is regenerated by `rust_eval/gen_report.py` on the acquisition host and
pushed here by cron, so this page tracks the live pipeline without anyone publishing
it by hand.

Served via GitHub Pages: **https://yasinel.github.io/gnps2-pipeline-status/**

The page reports only aggregate pipeline state and public repository accessions
(MassIVE / MetaboLights / Metabolomics Workbench). No credentials, hostnames, IP
addresses or local filesystem paths are included — a scan for those runs before each
publish and the push is skipped if any appear.
